# XIN HUI

There is a manufacturer mentioned on the AA2 remote "XIN HUI A.A. Electronics LTD", so lets try and find some more details.

This leads us to the following pages

A page with the [controller listing](https://aaeil.ecvery.com/products/remote-control/p1565630/ir-ceiling-fan-remote-control-receiver-model-no-aa2009-9.html). It mentions among other things that it is compatible with the following remote models: AA1, AA2, AA3, DD1, DD2, DD3 (of which we know of AA2 and AA3). At the bottom of the page there are links to other products like the remote moduls and some other controllers like AA2009-9RF (which is an RF controller)
